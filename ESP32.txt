Цель проекта
Разработать три программных модуля для microcontroller ESP32 с использованием среды разработки VSCode и PlatformIO. Проекты должны быть организованы в системе контроля версий Git и предоставлены вместе с инструментом загрузки espdownloader.
(изучить документацию)
Общие требования
Среда разработки: VSCode с платформой PlatformIO.
Контроль версий: Все разработки должны вестись в Git репозитории с понятной структурой коммитов и описаниями.
Инструмент загрузки: Включить в репозиторий espdownloader для загрузки прошивок на устройство.
Разделение программ: Каждая из трёх программ (загрузчик, рабочие программы) должна быть разделена по адресам памяти и иметь свои собственные bin файлы.
Документация: Предоставить README с инструкциями по сборке, загрузке и использованием программ.
Описание программных модулей


1. Загрузчик (Bootloader)
Функции:

1. Инициализация периферийных устройств ESP32 (GPIO, UART и др.).
2. Вывод текстовой информации о готовности к работе через UART. 
3. Переход к выполнению второй программы (Program2) после инициализации.
Требования:

1. Использовать выделенную область памяти для загрузчика. 
2. Обеспечить корректное переключение до Program2.
3. Настроить UART с параметрами: [указать скорость, например, 115200 бод].
Пример вывода в UART:

Bootloader: Инициализация завершена. Переход к Program2.


2. Вторая программа (Program2)
Функции:

1. Моргание светодиодом два раза с интервалом в 500 мс между миганиями.
2. Ожидание нажатия кнопки для перехода к третьей программе (Program3).
3. Отправка через UART сообщения о текущей работе раз в секунду.
Требования:

1. Использовать GPIO для управления светодиодом и чтения состояния кнопки.
2. Реализовать устойчивую обработку нажатий кнопки.
3. После подтверждения нажатия кнопки перейти к Program3.
Пример сообщений через UART:

Program2: Работаю...


3. Третья программа (Program3)
Функции:

1. Моргание светодиодом три раза с интервалом в 500 мс между миганиями.
2. Ожидание нажатия кнопки для выполнения переходов:
Длительное нажатие (более 1 секунды) → переход в загрузчик (Bootloader).
Короткое нажатие (менее 1 секунды) → переключение обратно на Program2.
3. Отправка через UART сообщения о текущей работе раз в секунду.
Требования:

1. Использовать GPIO для управления светодиодом и чтения состояния кнопки.
2. Реализовать таймер для определения длительности нажатия кнопки.
3. Обеспечить корректное переключение между программами в зависимости от длительности нажатия.
Пример сообщений через UART:

Program3: Работаю...


Функциональность:

Инструмент для загрузки bin файлов соответствующих программ на ESP32.
Поддержка загрузки различных модулей (Bootloader, Program2, Program3) по их адресам памяти.
Требования:

Скрипт или утилита, интегрированная с репозиторием, обеспечивающая удобную загрузку прошивок.
Документация по использованию espdownloader в README.md.
